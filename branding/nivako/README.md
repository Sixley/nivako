# NIVAKO Branding Profiles

Dieses Verzeichnis hält die lokalen Branding-Profile für zwei geplante Windows-Clients:

- `quicksupport` → Kunden-Version
- `remote` → Techniker-Version

Die Profile werden vom Skript `tools/apply_nivako_branding.py` genutzt, um die wichtigsten Windows-/Portable-Metadaten umzuschreiben.
